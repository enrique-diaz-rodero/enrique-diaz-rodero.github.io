# Portafolio Personal - Enrique Díaz Rodero

¡Bienvenido a mi portafolio web! Este es un proyecto personal diseñado para mostrar mi perfil profesional, mis habilidades técnicas (skills), certificaciones y experiencia como estudiante de Desarrollo de Aplicaciones Multiplataforma.

## 🚀 Características

- **Diseño Responsive:** Adaptado para dispositivos móviles, tablets y escritorio.
- **Filtro de Skills Interactivo:** Los visitantes pueden filtrar mis habilidades por categoría (Lenguajes, Frameworks, Herramientas, IA, etc.) usando JavaScript puro.
- **Sección de Certificaciones:** Acordeón interactivo para ver detalles de certificaciones sin saturar la página.
- **Navegación Sticky:** Menú de navegación fijo que facilita el desplazamiento por las secciones.
- **Diseño Moderno:** Uso de gradientes, sombras y transiciones suaves para una experiencia de usuario agradable.

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica del sitio.
- **CSS3:** Variables CSS, Flexbox, transiciones, animaciones y diseño responsive.
- **JavaScript (Vanilla):** Lógica para el filtrado dinámico de las Skills.
- **Git y GitHub:** Control de versiones y despliegue.
